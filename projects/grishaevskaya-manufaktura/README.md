# Гришаевская Мануфактура — сайт

Статический сайт (HTML/CSS/JS, без сборки и зависимостей) на основе Design Book v1.0
(июль 2026), брифа, переписки с заказчиком и реального профиля на Профи.ру.

## Как посмотреть

Файл полностью самодостаточный — просто открыть `index.html` двойным щелчком
(или перетащить в браузер). Сервер не нужен, интернет тоже не нужен (кроме
загрузки шрифтов — см. ниже). Ничего рядом класть не надо: CSS и JS лежат
внутри самого `index.html`, поэтому файл можно спокойно пересылать как
одиночное вложение, не боясь, что он «развалится» без соседних папок.

## Что внутри

Один файл `index.html`: разметка одностраничника (шапка, hero, услуги,
портфолио-карусель, преимущества, процесс, отзывы, о компании, FAQ, форма
заявки, футер), стили (`<style>` — палитра и структура блоков по Design Book:
`#714E44` орех, `#DCCFC2` песок, `#F7F3EE` крем, `#6B866F` шалфей, `#2A2A2A`
графит) и вся интерактивность (`<script>` — скролл-хедер, мобильное меню,
аккордеон FAQ, карусель проектов, отправка формы в WhatsApp) — всё вместе,
без сборки и внешних зависимостей.

## Иконки

Сознательно без стандартного набора outline-иконок (как в конструкторах вроде
Tilda) — вместо пиктограмм для услуг использованы крупные акцентные цифры
(01–06), а в карточках портфолио — двухбуквенные монограммы засечным курсивом
(«Кх», «Шк», «Гд» и т.д.), перекликающиеся с монограммой основателя («ЕГ») в
блоке «О компании». Из иконок остались только по-настоящему функциональные —
телефон, WhatsApp, Telegram, почта, метка на карте, стрелки — без них эти
ссылки было бы не считать глазами.

## Шрифты

Golos Text (текст/UI) + Unbounded (заголовки, geometric display — в духе
референсов KONSTRUKT/Gogol/Bebas, но с полной поддержкой кириллицы) + PT Serif italic
(тёплый акцент в цитатах и подзаголовке). Подключены через Google Fonts — в песочнице
сборки этот CDN был недоступен (сетевая политика окружения), поэтому в скриншотах
видны фоллбэк-шрифты; на реальном хостинге с открытым интернетом подключится штатно.

## Важно: фото проектов

Хотлинк реальных фото с текущего сайта (`grishaevmf.ru`, домен `selstorage.ru`) был
заблокирован сетевой политикой окружения, где собирался сайт — поэтому вместо реальных
фотографий в блоке «Работы и цены» стоят кодовые заглушки (градиент дерева + иконка).
Портфолио вместо этого ссылается прямо на профиль на Профи.ру (416 фото, 60 отзывов) —
это по факту решает задачу «показать реальные работы», не дожидаясь фотосессии.

**Что сделать, когда появятся фото:** внутри `index.html`, в скрипте, найти массив
`CASES` — у каждого объекта заменить `.case-swatch` (сейчас генерируется как
css-градиент) на `background-image` с реальным фото. Вёрстка и carousel-эффект
(«выступающая» активная карточка) уже готовы и переделки не потребуют.

## Адрес — есть расхождение, надо уточнить у заказчика

На текущем сайте (`grishaevmf.ru`) указан адрес «г. Троицк, Дальняя ул., 6» — этот
вариант сейчас стоит в контактах и в футере. В официальном профиле на Профи.ру
(«Данные компании проверены») указан другой адрес: «д. Десна, поселение Десеновское,
Центральная ул., 140». Возможно, это два разных объекта (шоурум/цех), а не ошибка —
надо уточнить у Евгения и поправить в `index.html` (секция `#cta`, блок `.cta-links`,
футер, и в скрипте — переменная `mapLink`).

## Дальнейшие шаги

- Подключить реальные фото проектов (см. выше).
- Подключить домен и захостить статику (Tilda, если нужно сохранить редактируемость
  без разработчика, либо любой статический хостинг — Vercel/Netlify/обычный хостинг,
  если ок держать код как есть).
- Подключить Яндекс.Метрику (счётчик уже был на старом сайте — id `88676125`).
- Когда будет ясность по офферам для дизайнеров/риелторов/застройщиков — можно добавить
  отдельный блок для партнёров (в текущей версии сознательно не добавлен, чтобы не
  придумывать за заказчика условия сотрудничества).
